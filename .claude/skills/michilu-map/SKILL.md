# 地図・地球演出と空間表現

## コードの入口
- `components/map-panel.tsx`、`components/live-map.tsx`、`components/full-map.tsx`、`lib/map-style.ts`、`lib/tiles.ts` と `lib/roadmap/` を必要に応じて読む。
- `package.json` のMapLibre GL、PMTiles、ベクトルタイル関連の実バージョンを確認する。記憶だけでAPIを決めない。

## 実装ルール
1. 住所・地番・地図選択のどこから始めても、実際に確定した座標へカメラを移す。日本の測地系・緯度経度の順序・ズーム・境界値をテストする。
2. 「地球 → 日本 → 対象物件 → 調査結果」を滑らかにつなぐ演出は、ユーザー操作を遮らず、読み込み中でも現在状態が分かるようにする。モーション低減設定と低性能端末向けの代替を用意する。
3. 既存の道路種別・都市計画・筆・ハザード・建物・地価などの表示順、凡例、データの有無表示、出典を壊さない。
4. PLATEAUのLOD1や建物属性は写真品質の街並みではない。高精細の都市画像を実現できない場合はその限界を説明し、模型的な3Dを無理に最終デザインとして提示しない。
5. Google Maps/Earth/Street View等の画像・タイルを利用条件に反してキャッシュ・抽出・再配布しない。新しい地図ソースは商用利用、帰属表示、転送量、API料金・上限、CORSを事前に確認する。従量課金の追加は承認なく行わない。
6. ピンやレイヤーのタップ判定、位置補正、WebGL不可時の静的表示、データ欠損時の表示を検証する。

## 検証
- 関東内の住所/地番、住所が曖昧な例、地点選択、区域境界、地図を動かしてからの再検索を確認する。
- 描画速度・転送サイズ・ブラウザメモリを意識し、重い読み込みは遅延化する。
- 「見た目を確認した」と書くのは実際に動作画面を確認できたときだけ。
