# スマホのオープニング CG「富士の目覚め」（作る道具）

スマホ（横幅 1024px 未満）で、アプリを開いたときに流すオープニング映像を作る道具。PC のオープニング（`scripts/pc-opening/`）と
同じ作り（Blender の Cycles で「面」を描き、空気と仕上げは numpy）に、体積の雲（numba）を足したもの。
映像そのものは全画面（1080×2340・縦長）で描く。映画の横長の帯（2.39:1）とロゴは、アプリが映像の上に描く。

## 構成（約 7.5 秒・30 コマ/秒・225 コマ。音なし）

光は朝日だけ。色は PC と同じ藍・金・白。白鳥は出さない（4 月下旬に富士の西を白鳥が渡ることはまず無い）。

| 秒 | 映すもの |
|---|---|
| 0.0〜0.6 | 静寂：夜明け前の藍の雲の中。奥（富士の方）から金の光が漏れる |
| 0.6〜2.4 | 上昇：加速して雲の中を真上へ（最も速いとき 約 300m/秒）。雲の切れ端がレンズの前を下へ流れ去る。雲が薄くなり、上に富士の影が透ける |
| 2.4〜3.2 | 突破：2.6 秒に雲海の頭のてっぺんを抜け、勢いがすっと止まる（約 100m/秒 → 30m/秒）。光が満ちる |
| 3.2〜5.6 | 対面：富士。4.2 秒に山頂の縁から太陽が出る（ダイヤモンド富士）。ゆっくり押し込みつつ少し回り込む（揺らさない） |
| 5.6〜7.5 | ロゴ：光が落ち着く（太陽は山頂の縁から 3 割ほど出たまま。ロゴはアプリが「山頂の光の点」から出す） |

0〜2.4 秒はアプリが帯をかぶせるので、見せたいもの（光の漏れ・透ける富士）は画面の真ん中の帯（高さ = 幅 / 2.39）に入れている。
画面の大きさは今のスマホの多く（19.5:9）に合わせた 1080×2340。古い 16:9 の機種では上下を切るので、大事なもの（山頂・太陽）は
真ん中の 1080×1920 に入れている（太陽は上から 36% の所）。

## 場所・日時（ダイヤモンド富士になるように計算）

- 2027 年 4 月 25 日 5 時 52 分（日本時間）。太陽は方位 80.5°・見かけの高さ 9.3°（大気の屈折を含む。NOAA の式で計算）。
- 4.2 秒のカメラ：北緯 35.3400°・東経 138.5750°、海抜 1,430m（田貫湖のすぐ東の上空、剣ヶ峰の西 14.0km）。雲海の頭の約 100m 上。
- カメラが雲海のすぐ上にいるので、山頂は高さ約 9.4° に見える。ダイヤモンド富士になるのは太陽がその高さに来たとき（日の出の約 45 分後）。
  田貫湖（湖面 650m）のダイヤモンド富士が 4 月下旬の 6 時すぎ（太陽の高さ 約 11°）なのと同じ理屈で、カメラが湖面より約 800m 高い分、
  少し早い。`path.py` が、4.2 秒に太陽の中心が山頂の縁の 0.15° 下に来るように、道筋の向きと時刻を解く。
- 各コマの太陽の画面上の位置（1080×2340 の画素）と、山頂の縁から出ている割合は `work/sun_px.json`（アプリがロゴの光の点を合わせる）。

## 作り方

必要なもの：Python 3.13・numpy・scipy・Pillow・OpenEXR、`numba`（体積の雲。`pip install numba`）、
Blender 5.3 を Python から使う版（`pip install bpy==5.3.0`）。下の `python` は bpy を入れたもの、`python3` はふつうの Python
（numba を入れたもの）。

```bash
python3 fetch.py                 # 標高タイル（5m・10m・約15m）→ work/dem5a・dem14・dem13
python3 path.py --report         # 太陽の時刻・道筋 → work/plan.json、各コマの太陽の位置 → work/sun_px.json
python3 cloudfield.py            # 雲海の上面の高さの地図 → work/cloudtop.npz
python film.py --frames 126 --scale 0.5 --spp 32 --threads 4 --denoise   # 面（地形・空・太陽）1080×2340 → work/film/0126.exr
python3 clouds.py --frame 126 --scale 0.5 --sub 2 --threads 4             # 体積の雲と空気（1080×2340）→ work/clouds/0126.npz
python3 post.py --frames 126     # 合わせて仕上げ → work/frames/0126.png（1080×2340）
python3 run_all.py --blender 〈bpy の python〉 --numba 〈numba の python〉   # 225 コマ全部（区間ごとの設定。途中から再開できる）
```

`--scale` は 2 倍の大きさ（2160×4680）に対する割合（0.5 で本番の 1080×2340、0.25 で 540×1170 の試し）。`film.py --preview` はノイズ除去つきの軽い試し。
`clouds.py --sub` は動きのぶれのための時間の分け数（レンズの前 40m は、速いときその 3 倍に分けて、流れ去る切れ端を筋にする）。

### 描く大きさと時間（この作業場所、4 コア。2026-11-21 の見た目の確認で測った）

1 倍（1080×2340）で描く。動画は 1.5〜2MB に縮めるので、2 倍で描いた細かさは残らない（2 倍が要る所は無かった）。
面はノイズ除去をかけ、かける前の絵と 7:3 で混ぜる（のっぺりしないように）。

| コマ | 面（film.py、32 サンプル） | 雲と空気（clouds.py、時間 2 分け） | 仕上げ（post.py） | 合計 |
|---|---|---|---|---|
| (a) 1.5 秒・雲の中 | 67 秒 | 163 秒（奥は半分の大きさ） | 約 5 秒 | 約 4 分 |
| (b) 2.8 秒・雲を抜けた所 | 83 秒 | 122 秒 | 約 5 秒 | 約 3.5 分 |
| (c) 4.2 秒・ダイヤモンド富士 | 91 秒 | 85 秒 | 約 5 秒 | 約 3 分 |

225 コマ全部は `run_all.py`（区間ごとに設定を変える。5.6 秒からは 3 コマおきに描いて間を混ぜる）で 約 8 時間の見込み。

| ファイル | 中身 |
|---|---|
| `common.py` | 画面の大きさ・時間・日付、太陽の位置（NOAA）と光の色、EXR の読み方 |
| `fetch.py` | 国土地理院の標高タイルを取ってつなぐ（取る道具は PC の `fetch.get`、座標は PC の `geo.py`） |
| `terrain.py` | 標高（5m → 10m → 約15m の順に細かい方）と、カメラから見た山の輪郭 |
| `path.py` | 時間割・カメラの動き（山頂からの方位・距離・高さ・画角）、ダイヤモンドの時刻を解く、太陽の画面上の位置 |
| `cloudfield.py` | 雲海の上面の高さ（カメラの通り道のまわり 8m、まわり 32m、遠く 200m ごと）。カメラが抜ける頭 |
| `film.py` | Blender（Cycles）で面を描く：富士（5m の標高。雪・砂礫・森）、空、太陽。雲海の上面はカメラに映さず、照り返しと影だけ |
| `clouds.py` | 体積の雲と空気（numba）。雲の形・雲自身の影・富士の影・太陽のまわりの明るい空からの光・多重散乱の近似・レンズ前の切れ端 |
| `post.py` | 合わせて仕上げ：地平線より下の空を暗い地面に、上の空を藍に、控えめなにじみ、ダイヤモンドの瞬間だけ横の光の筋、AgX（藍・金・白）、2 倍から縮めて細かい粒 |
| `work/` | 取ったタイル・描いたコマ（Git には入れない） |

## 本物らしくするためにしたこと

- 地形：山頂のまわり（約 ±2km）は 5m の標高（航空レーザ測量）を約 3.9m ごと、西の面と左右の肩は約 7.8m ごと、山全体は 10m。
  溶岩の筋と沢は、山頂から放射状にのびる細かい起伏（Cycles の起伏）、砂礫のざらつきも細かい起伏で。
- 雪：4 月下旬の残雪。雪の線は約 2,500m（南向きは高く）、沢（へこみ）に沿って低くまで残り、尾根（出っ張り）と急な岩（約 45° より急）は地肌。
  縁は風で削られたように鋭く、細かくぎざぎざ。雪線より下の沢にも細い残雪（2,100m くらいまで）。雪は光が中で散る（影は空の青を吸った色）、
  夜に凍り直した薄い氷のつや（むらのある透明な上塗りと、風紋の細かい波）。凍った砂礫も少しだけ光る。真っ白には塗らない。
- 雲：雲海を「上面の高さの地図」と 3 次元のゆらぎで作った体積の雲（もくもくの頭・ちぎれた縁）。雲自身の影は太陽の方へ光の道をたどって数え、
  近くの雲は細かい形で数える（頭のふちが光り、くびれが暗い）。何度も散る光は Wrenninge（2013）の近似。
  ダイヤモンド富士のとき、手前の雲海は必ず富士の影の中なので、直接の日は当たらない。代わりに、山頂の上の明るい空（太陽のまわり）からの光が
  雲の薄い縁を前へ抜けて光る（銀の縁）。雲の中は深いほど藍に沈み、富士の影の外の日の当たる雲から、光が影の中へにじむ（金の光が漏れる）。
- 空気：空気の分子（遠くほど青い）、雲の上にたまるかすみ、春の細かいちり（太陽のまわりが金に明るい）。富士の影の所は光らない（光の筋）。
- 太陽：本当の大きさ（0.53°）。にじみは控えめ。映画用レンズの横に伸びる淡い光は、ダイヤモンドの瞬間（3.7〜4.9 秒）に一筋だけ。

| データ | 使う所 | 出典の書き方・条件 |
|---|---|---|
| 国土地理院 標高タイル（基盤地図情報数値標高モデル）。`dem5a_png`（5m、ズーム 15）・`dem_png`（10m、ズーム 14・13） | 富士山とまわりの地形 | 地理院タイル一覧の「■2. 基本測量成果以外で出典の記載のみで利用可能なもの」。「国土地理院」または「地理院タイル」と書き、[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)へのリンクを付ける。加工したことも書く。国土地理院が作ったように見せない（[利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)） |

出典の書き方の例：「標高：国土地理院 標高タイル（5m・10m）を加工して作成」（地理院タイル一覧へのリンク付き）。
空（Blender の空の計算）・雲・かすみ・光は、データを使わずに計算で描いたもの。写真のタイル・Google の地図や 3D の画像は使わない。
