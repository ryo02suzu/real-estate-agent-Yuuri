# PC のオープニング第4版：制作計画

第2版（`scripts/pc-opening`。日本列島 → 北アルプスへ降りる → 上高地を鷹の目で飛ぶ → 雲海と朝日 → 白鳥 → ロゴ）の流れを土台に、
画質・本物らしさ・飛び方を作り直す。第3版（`scripts/pc-opening3`）の森の仕組みと、赤富士の試し（`scripts/gpu-render`）の雲の仕組みも使う。
この計画が、手分けして作る人（手伝いの作業場・ワークフロー）みんなの決まり。変えるときは、この紙を先に直す。

## 3. 場面ごとの作り方

- **A・B（宇宙から）**：第2版の列島の場面（`film.py` の `build_global`・`atmos.py` の大気）を 4K 向けに作り直す。陸の色は地理院タイル（ランドサットのモザイク、
  近づく所は全国最新写真）。雪は標高で足す。夜の街の明かりは、ホームで使っている国勢調査の人口からの明かり（`night_lights.py`）。海は太陽の照り返し。
  雲は、ホームの雲で作った「宇宙から見た雲の形」（`air_clouds.py` の 2 版）を薄い層にして影を落とす。夜明けの線（明暗の境）と大気の縁は物理の式で。
- **雲を抜ける**：白い雲の中で場面を替える。雲は奥行きのある白（一様な白い板にしない。雲のかたまりが手前から流れる）。
- **C（岩と雪）**：地形は 5m の標高（無い所は 10m）。遠くの色は航空写真（写り込んだ影は、標高から計算した撮影時の影で割って消し、今の朝日で照らし直す）。
  カメラから 300m 以内は、写真から作られた岩・ガレ・雪の素材（Poly Haven・ambientCG。CC0）を、向きによらず貼り（3 方向から）、細かい凹凸を本当の形として足す。
  新雪は、標高・傾き・くぼみで積もらせる。岩のかけら・大きな石を見せ場の近くにだけ置く。
- **D（森と川）**：木は木の素材集（`trees/`）。どこに何が生えるかは、標高・傾き・向き・川からの距離・航空写真の色で決める（カラマツは林でまとまる。ダケカンバは
  森のふちと上。モミ・シラビソ・コメツガは北向きと上。ケショウヤナギは川原。2,500m から上はハイマツ。すき間・倒木・立ち枯れを入れる）。等間隔にしない。
  川は第3版の川筋をもとに、幅と州を写真に合わせ、浅い澄んだ水（底の石が見え、空と山が映り、流れのさざ波）。朝もやは立体の薄い霧（川の上と谷の低い所）。
- **E・F・G（尾根越え・雲海・白鳥）**：雲海は赤富士の試しで作った立体の雲（高さの絵＋小さな入れ物に分ける）。遠くの山（八ヶ岳・富士山・南アルプス）は
  広い範囲の標高で形を作り、朝の空気で影絵にする。雲海は遠くてやわらかいので、雲だけ 4 分の 1 の細かさで描いて重ねてよい。白鳥は `swan_hero.py`。
- **空気と仕上げ**：遠くの青いかすみ・谷の朝もや・光の筋は、奥行きを使って足す（第2版 `atmos.py`・第3版 `post3.py` の式）。色は AgX。動きのぶれは本物のシャッター
  （180°）。レンズのにじみ・粒・周辺の暗さは控えめに。太陽を正面に見る場面のフレアは使わないか、ごく弱く。

## 4. 共通の決まり

- **座標**：東・北・上（m）。原点は河童橋（緯度 36.2490・経度 137.6380・標高 0）。高さは本当の標高（強調しない）。遠い所は地球の丸みの分だけ下げる。
  宇宙の場面は第2版の座標（km）を使ってよい（雲の中で替えるので、つなぎは向きと降りる角度だけ合わせる）。
- **時間**：24 コマ/秒・600 コマ（0〜599）。コマ f の時刻は f/24 秒。場面の切り替えは 5.45 秒（コマ 131 から山の場面）。
- **光**：太陽の方位 115°（北から時計回り）・高さ 5°（山の場面を通して同じ）。空は Blender の空の計算（多重散乱）。色の扱いは AgX。
- **乱数**：木・石・羽など、ばらつきは全部、物の番号から決める（`np.random.default_rng((種類, 番号))`）。描く機械・コマの組が違っても同じ絵になること。
  カメラから見えるかどうかで乱数を引く順番が変わる作りにしない（第3版はこれで森がちらついた）。
- **細かさの段（LOD）**：0＝すぐ近く（20m 以内）、1＝近く（150m 以内）、2＝中（800m 以内）、3＝遠く（それより先。その木自身の絵を貼った板）。段の切り替えは、
  全部のコマのカメラの位置から決める（コマの組ごとに変えない）。
- **置き場**：`scripts/pc-opening4/`。作業の材料は `work/`（git に入れない）。確かめの絵は `review/<名前>/`（JPEG・横 1600px まで・1 枚 400KB まで）。
- **道具**：Blender 5.3（Python の bpy）・Cycles・CPU。お金のかかる物は使わない（Runpod は残り 5.21 ドルの範囲だけ）。素材は使ってよい条件を元のページで確かめ、
  `ASSETS.md` に出所を書く。Google の地図・画像は使わない。

### 素材集に求めること（場面を組む側との約束）

- 木：`trees/library.py` の `build_library(species, variants, lods)` が、名前 → 1 本ぶんの物（幹・枝・葉をまとめた 1 つのメッシュ。原点は根元・上が +Z・単位 m・
  本当の大きさ）を返す。名前は `<種類>-<番号>-lod<段>`。種類：`larch`（カラマツ）・`birch`（ダケカンバ・シラカンバ）・`fir`（シラビソ・モミ・トウヒ・コメツガ）・
  `willow`（ケショウヤナギ）・`pumila`（ハイマツ）・`snag`（立ち枯れ・倒木）・`under`（ササ・シダ・草・低木）。
- 白鳥：`swan_hero.make_hero(name, phase0)` と `set_pose(sw, phase)`。原点は体の真ん中・前が +Y・単位 m。

## 5. 描く計画

- 測ったこと（2026-11-24。この作業場＝CPU 4 つ）：第3版の森の場面を 3840×2160・64 回で 1 コマ 50.8 分、メモリ 7.6GB（GitHub の機械 16GB に入る）。
- 見込み：山の場面 469 コマ × 平均 40〜60 分 ≒ 300〜470 台・時間。宇宙の場面 131 コマは軽い（1 コマ 5〜10 分）。
- 描く機械：GitHub Actions（無料。同時に約 20 台・1 回 6 時間まで）で 1〜1.5 日。足りない所だけ Runpod の GPU（残り 5.21 ドルの範囲）。
  手伝いのクラウドの作業場は Claude の使用量を使うので、描くだけの仕事には使わない。
- 重い層を分ける：雲海と朝もや（立体の雲）は 4 分の 1 の細かさで別に描いて重ねる。白鳥も別の層（背景は透明）。
- 中間の絵は 16 ビット（EXR か 16 ビット PNG）。最後に AV1（10 ビット）4K・1440p・1080p と、HEVC・H.264 を作る。

## 6. 確かめ方

1. 道すじ：下書きの動画（小さく速く描いたもの）で、速さ・高さ・景色の流れる速さの表と一緒に見る。つまらない所・流れすぎる所を直す。
2. 素材：木・岩・白鳥・雲それぞれの確かめの絵を、厳しい目（作り物に見える所を探す役）に見せ、直す。見つからなくなるまで。
3. 大事な止め絵 6 枚を 4K で：A（1.8 秒・夜明けの線が日本を横切る）、C2（8.8 秒・吊尾根を越える瞬間）、D2a（12.6 秒・カラマツの梢）、D2b（13.8 秒・梓川）、
   E（17.9 秒・尾根を越えて朝日と雲海）、F（20.0 秒・白鳥）。持ち主に送る。
4. 動画：同じコマを 2 つの組で描いて同じ絵になること（ちらつきの検査）。全部のコマがそろうこと。
5. アプリ：`lib/app/opening.ts`（長さ 25.0 秒・ロゴ 19.8 秒から・消えるのは 24.2〜24.9 秒・4K の映像を足す）、出典の表示、`npm run lint`・`typecheck`・`test`。

## 7. 危ない所と手当て

| 危ない所 | 手当て（先に確かめること） |
|---|---|
| 近くの岩・地面が写真の引き伸ばしでぼやける | 見せ場①の止め絵を最初に作る。300m 以内は写真の色を使わず、岩の素材と本当の凹凸で作る |
| 森が同じ木の繰り返しに見える | 木の素材集の「森の試し」（300 本以上・混ぜて植える）で、同じ木が見つからないことを確かめる |
| 谷底が影で、暗くのっぺり見える | 空の光と、朝焼けの壁からの照り返しで照らす。朝もやと水の映り込みで明るさを作る。見せ場②の止め絵で確かめる |
| 立体の雲が重い | 4 分の 1 の細かさで別に描く。遠い雲海は高さの絵の面にして、近くだけ立体にする |
| 手分けして描くとちらつく | 乱数は物の番号から。段はすべてのコマから決める。同じコマを 2 つの組で描いて比べる |
| Claude の使用量の上限で作業が止まる | 仕事を小さく分け、区切りごとにファイルに残す（各担当は `NOTES.md` に進み具合を書く）。止まっても続きからやり直せるようにする |
