# 宇宙からの場面（パッケージ globe, 手順 1）：地球・光・A の場面

担当ファイル: `globe.py`（描く）、`globe_fetch.py`（材料を集める）、このファイル、`review/globe/`。材料の置き場 `work/globe/`（git に入れない）。
コマ 0〜135（5.625 秒）。コマ 131 から山の場面。コマ 120〜135 は雲の中の真っ白（コマ 118→126 で白へ、126 以降は完全に白）。

## 使い方

```
# 1. 材料を集める（python3 + numpy + Pillow だけ。約 20 分・取ったものは work/globe/raw に残る。二度は取らない）
python3 scripts/pc-opening4/globe_fetch.py --data scripts/pc-opening4/work/globe
# 2. 描く（Blender 5.3 でも、bpy を入れた Python でも同じ）
blender -b --factory-startup --python scripts/pc-opening4/globe.py -- data=work/globe out=out frame=77 res=3840x2160 samples=64 threads=2
#   frame=77 / 0-135 / 0,12,24   border=x0,y0,x1,y1（左上が原点の画素）   exr=1（線形の EXR も出す）   denoise=1
```
出力は `globe_<コマ>.png`（AgX で仕上げ済みの 8bit）と、exr=1 のとき `globe_<コマ>.exr`（空気を足したあとの線形・露出は掛け済み）。
`python3 -c "import globe; globe.camera_state(60)"` のように、カメラ・太陽・露出は bpy なしでも関数で読める（`project(frame, lat, lon)` で緯度経度が画面のどこに写るかも出せる）。

## 作りの要点

- 地球は半径 6371 km の球（1 単位 = 1 km）。世界座標は北アルプス（36.29N 137.65E）の海面が原点の 東・北・上。海が球の外へ落ちる分も球そのもの。
- 材料は緯度経度の絵を 3 段に重ねる: G（世界 8192x4096）→ R（経度 120〜152・緯度 24〜52 を 0.006°=約 650 m）→ C（中部 135.5〜140.5E・34〜38.5N を 0.0014°=約 150 m）。
  種類: rgb（色。陸は地理院の写真、海は Blue Marble、雪は標高から）・land（陸の印。ナチュラルアース 10m）・relief（R=東向き斜面・G=北向き斜面・B=太陽の方位 115° の地平線の高さ角 0.1° 単位）・lights（夜の灯り。にじみ付き）・cloud（雲の濃さ）。標高そのものは `R_dem.npy`・`C_dem.npy`（float16・m）。
- 地形の影は「地平線の高さ角の地図」と、その場の太陽の高さを比べて決める（太陽の方位は 115° 固定）。斜面の向きは法線で曲げる（強調 1.6 倍。`relief=` で変える）。手順 2 で山が近づくところは本物の面と細かい標高に替える前提。
- 雲は半径 +3.5 km の薄い球（濃さの絵で透明度を決める）。地面に雲の影が落ちる（Cycles の光線）。雲の絵は NASA の毎日の真色画像から「観測 = 地面×(1−a) + 白×a」で a を解いて作った（色のついた物は外し、標高 1800〜2400 m 以上は雪として雲にしない）。
- 空気（青い縁・朝焼けの帯・もや）は、描いたあとに numpy で 1 画素ずつ光線をたどって足す（レイリー・ミー・オゾン。太陽の光が通る空気の量は表にして引く。大きな絵では半分の細かさで計算して線形補間）。
  太陽の光の色（高さの関数）と空の明かりは、同じ表から作った 512x2 の 1 次元の画像を材料に渡して使う（地面・雲・海が同じ光の色になる）。
- 灯りは陸の上だけ、太陽が上がると −6°〜+2° で消える。雲の下は弱める。色はオレンジ〜白のゆらぎ（雑音）。
- 星はごく暗い 2600 個（種 20261127）。露出は「絞り」のかわりに時刻の関数（0 秒 +3.2 段 → 3.4 秒 +5.2 段）。

## カメラ（コマ番号だけの関数 `camera_state`）

出だしの 3 つの置き場（北北東 nne・東北東 ene・南東 se）を 480x270 で試した（`view=` で今も切り替えられる）。
**北北東から南南西へ向かう nne を採用**（終わりの向き 200° と同じなので回さずにすむ・列島が斜めに伸びて本州から九州までが一度に読める・太陽が左から横に当たって影が見える・太平洋が左で朝日が先に当たる）。
ene・se は列島が縦に立つか手前に縮み、読みにくかった。
- 位置: 北アルプスから方位 20° の側へ、地面ぞいの距離 D と高さ h。D = 1450 → 1000(1.7 秒) → 550(3.4 秒) → 160(4.3 秒) → 18(5.2 秒) → 6 km、h = 1150 → 820 → 300 → 110 → 8 → 3.3 km（対数で補間）。
- 向き: 出だしは地平線が画面の上のほうに来る下げ角（地平線の見かけの下がり + 視野の 42%）、3.5 秒までに「北アルプスの少し先」を向くほうへ移る。5.2 秒で向き 200°・下げ角 9°・高さ 8 km。
- レンズ 35 mm（3.4 秒まで）→ 5.2 秒で 28 mm（山の場面の始まりと同じ）。モーションブラー（シャッター 0.3）。
- 太陽: 北アルプスでの高さ −14°（0 秒）→ −4.5°（1.8 秒）→ −0.5°（2.6 秒）→ +2.2°（3.4 秒）→ +5.0°（5.458 秒）。方位は常に 115°。
- 確かめた: コマ 0 で札幌・青森・東京・福岡・鹿児島がすべて画面に入る（北海道は下のふちぎりぎり）。

## 作りの要点（足し分）

- 材料に 2 段足した。M = z12（約 36 m/画素・136.9〜138.5E, 35.6〜37.25N）、F = z14（約 10 m/画素・137.38〜137.95E, 36.0〜36.66N）。
  色（地理院の写真を C に色あわせ・11 月の新雪を雪線 + 雑音 + 斜面で）、斜面（感度 112 で保存。読む側で 180 に直す）、太陽の方向の地平線（F は近く 14 km まで自分で、遠くは M の地平線）。
  `M_low.png` = 谷にたまる雲（高さ 1,500 m 以下の盆地・谷。山の東側を厚く）。
- 面（本物の起伏）：`terrain_mesh`。カメラの足もとを中心にした入れ子の四角い輪（目の大きさ 15 m〜 距離が倍で目も倍）。画面に入る所だけ作る。
  輪の境目は、細かい側のふちの「間の点」を荒い側の線に乗せて隙間を無くす。標高は R→C→M→F を絵と同じ窓で重ねた関数 `Height`。
  高さの倍率は 56→84 コマで 0→1（ぽんと出さない）。面は影を落とさない（影は地平線の絵と雲の球）。材料は球と同じ式（頂点は世界座標なので地球中心座標へ直して使う）。
- 雲海：M の範囲の格子（高さ 1.52 km・うねり 70 m）に `M_low` を貼った雲の材料。
- 雲の層（高さ 2.4〜9.6 km、`cloud_deck`）：描いたあとに視線に沿って数値でたどって足す。薄いちぎれ雲（7.6〜9.6 km）は少しずつ増え（切れ目の数はコマで決まる）、コマ 119〜125.5 で芯が育って一面の白になる。
  最後の白は AgX を通すとちょうど #f3f1ec（`END_LIN`）。コマ 123〜129 でその一様な白へ。ごくわずかな動くむら（±1.5 %）が残る。
- 雲の球・雲海は透明の確率ゆらぎで粒が出るため、「地面だけ（雲は影だけ）」と「雲だけ（サンプル数を増やす）」の 2 回に分けて描き、合成する。
- カメラ：3.4 秒から急降下し、4.7 秒から強くゆるめる（尾根をじっくり見せる）。5.1 秒に雲の層の上のふち、5.458 秒に高さ 3.05 km。向きは 200°。急降下の間だけ 9° 下を向く（地平線が画面から外れ、また戻る）。
