# terrain（地形：吊尾根のヒーロー止め絵）進み具合

## できたこと（2026-11-25）
- データ：`terrain.py fetch` で国土地理院の DEM1A（1m・約 2.7km 四方）・DEM5A（5m・約 8.8km 四方）・航空写真 z17 を `work/terrain4/` に取る（4 枚/秒・タイルは保存）。
  谷の 10m（pc-opening3 の valley.npy）・far・mid（広い範囲）は読むだけ。`Height` が細かい順に縁をなだらかに重ねる（3 次補間）。
- 面：`Rings` ＝ 中心のまわりに 12 枚の四角い輪（細かさ 0.125m → 256m、半幅 32m → 65km、各 512×512 マス）。穴の境にスカート。
  岩の形は `rock_detail`：割れ目の向き（JOINT_A 38°・JOINT_B 118°）にそろえた伸びたボロノイのかたまり 6 段（0.9〜150m。上面が傾き、縁が面取り、境は溝）＋層の棚 4 段（1.6〜44m）＋ガレの石。
  細かさ ceff より細かい段は自動で切る（輪の境でなめらかにつながる）。新雪は `snow_field`（傾き・くぼみ・風にさらされる尾根・標高・まだら）で厚さを高さに足し、濃さを頂点の snow に持つ。
- 材質（`ground.py`）：岩 3 種（rock_face_04 / quarry_wall / dark_rock_02）＋ガレ（gray_rocks）を 3 方向（Box）から貼り、3 つの大きさ（約 2.3 / 6.9 / 19.7m を互いに割り切れない値・向きも変える）を重ね、
  色は雑音で混ぜる。地衣類の暗い斑・さび色・写真の色むら・割れ目の暗さ。雪は頂点の snow ＋ 細かい雑音 ＋ 岩の凹凸の高さ ＋ 凹凸後の上向きの度合いで縁をほぐす。
  かすみは材質の中（距離で exp(-σd)、見えなくなった分はその向きの空の色）。世界の体積は使わない（無限に続いて空も消える）。
- 置く岩：Poly Haven の 15 種（細かさの段つき）を 360 個。`place_rocks`（場所だけから決める乱数）。大きさ 0.45〜15m・向き・沈み具合をばらす。
- カメラ：`work/route.json` のコマ 240（10.0 秒）に合わせる（尾根の 18m 上・向き 201°・傾き -9.9°・横の傾き -0.8°・61m/秒）。
- 描き方：`python terrain.py render hero|back --res 3840x2160 --spp 128 [--blur] [--out PNG] [--borders "x0,y0,x1,y1;..."]`
  （bpy 入りの Python で。2 スレッド固定。`--borders` は 4K の画面のまま枠の中だけ描く＝1:1 の切り出し）。

## 分かったこと
- 世界の体積のかすみは使えない（空が真っ暗になる）。
- 向き 201°・尾根の 18m 上では、足元の尾根は画面の下に出ない（尾根は 33° で落ちる）。近い岩は左右の下の角に出る。
