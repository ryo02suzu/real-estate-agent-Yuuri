# ホームの帯の街（PLATEAU）の焼き込み

ホームの帯は、写真ではなく **国土交通省 PLATEAU の実在の建物** と **地理院タイル** から作った街を、アプリが今の太陽・空・天気で照らして描く（`components/app/sky-canvas.tsx`）。ここは、その街を「焼き込む」手順。

- 視点：汐留の上空 260m（北緯 35.6640°、東経 139.7616°、楕円体高 296.7m）、方位 246°、水平画角 62°、上向き 0.25°（`geo.py` の `CAM`。アプリの `HOME_CAMERA` と同じ）。
- 建物：港区・渋谷区・目黒区・品川区・世田谷区・大田区・杉並区・狛江市・調布市・川崎市（`sets.json`）。10km までは質感付きの LOD2、その先は LOD1。遠くの低い建物（6km 先で 9m 未満、10km 先で 22m 未満）は画面で 1 画素に満たないので地面の写真に任せる。PLATEAU の東京タワーは外し、`tower.py` の格子の模型に替える。
- 地面と山：地理院のシームレス空中写真と標高（DEM5A・DEM10）。近くは 1m、遠くは富士山（約 100km）まで。地球の丸みと大気の屈折（k=0.13）を含む。
- 夜の街灯：地理院の道路中心線（experimental_rdcl）。
- 東京タワー：`tower.py` が本物の寸法と写真で測った外形・梁の高さ・塗り分けから格子の模型を作る。街の層は塔を抜いて描き（`renderPass(..., { hide: [4] })`）、塔だけを画面の一部（`tower-region.json`、1pt あたり 24 画素）で描いて `post5.py` が縮める（`twa.webp` 色と被覆、`twd.webp` 面の向きの割合と照明の属性）。描く側の `TOWER`（`components/app/sky-canvas.tsx`）に `layers/tower.json` の距離と向きを入れる。
- 形を作り直す高層ビル：`landmarks.py`（麻布台ヒルズ森JPタワー）。PLATEAU の同じ建物を抜き（`landmarks.json` の exclude）、頂点の色で外装を描く。
- 外装を作り直す高層ビル：`facades.json`（愛宕グリーンヒルズ MORI・フォレスト、麻布台ヒルズ レジデンスA、アークヒルズ仙石山森タワー、泉ガーデンタワー、六本木グランドタワー、六本木ヒルズ森タワー、ミッドタウン・タワー）。PLATEAU の空中写真の質感はぼやけるので、形はそのままに `post2.py` が実際の階数で各階の帯・ガラス・方立を描く（ガラスは窓として扱う）。色は写真から。
- 焼き込みは画面の 4 倍（4716×3300）。`post3.py` がカメラのレンズと同じ形（ガウス＋画素の箱、合わせて標準偏差 0.55 画素）で 3 倍・2 倍の端末の画素に縮める（平均だけだと輪郭が階段状に残る）。
- 航空障害灯（`post4.py`）：航空法の決まりどおり、60m 以上の屋上の両端に赤、90m 以上は明滅、150m 以上は昼は白い閃光、105m を超える建物は中間の高さにも不動の赤。種類は `lights.json` の 4 列目（0 不動 1 明滅 2 東京タワーの頂 3 展望台 4 150m 以上）。

## 実行

```
./run.sh
```

`work/` にデータ（約 2GB）を置き、`public/home/city`（3 倍・2 倍の端末用の層と、影用の高さ地図・航空障害灯）を書き換える。仕上げ（`post3.py`）では、縮めて柔らかくなった色を少しだけ研ぐ（カメラの輪郭強調と同じ程度）。東京タワーの部材は遠目の格子の密度に合わせて実寸より少し太い（`tower.py`）。

## 出てくる層（`public/home/city/{2x,3x}`）

| ファイル | 中身 |
|---|---|
| `albedo.webp` | 色（RGB）と街の被覆（A） |
| `normal.webp` | 面の向き（RGB、6bit）と空の見え方（A、4bit） |
| `geo.webp` | 距離（RG、対数 12bit）・種類と補助（B：上位 3bit が種類＝1 建物（質感）2 建物 3 地面 4 塔 5 木 6 山、下位 5bit が建物の用途か道の太さ） |
| `win.webp` | 窓の被覆（R）・点灯の鍵（G。オフィスは 4 列、住宅は 2 列、ホテルは 1 列のまとまり）・階の鍵（B） |
| `emis.webp` | 塔：部位と段（R）・ランドマークライトの当たり（G）。地面：道の被覆（R）・向き（G）・道に沿った座標（B）。山：標高 /16（R） |
| `dsm.webp` | 真上からの高さ（2048 四方・9km、値×1.6−300m）。視界の周り 600m の外は地面の高さ |
| `lights.json` | 航空障害灯 `[x, y, 距離, 種類, 位相, 周期]`（60m 以上の建物の見えている屋上の端、東京タワー） |

## 代わりの絵（`public/home/sky`）

WebGL が使えない端末と読み込み中に見える CSS の層。ビルドしたアプリを、文字を隠してキャンバスだけ撮る：昼 `#t=2026-10-26T11:30&w=clear&h=50&l=0`、夕焼け 15:50、薄暮 17:00、夜明け 05:35、夜 20:00（それぞれ `&l=0` で人工の明かりを消す）、夜の明かり＝20:00 の明かりあり − なし。街のマスク `city-mask.png` は `albedo` の被覆。

## 出典

国土交通省 PLATEAU（3D都市モデル、各区市の年度版）を加工して作成。国土地理院 地理院タイル（シームレス空中写真・標高タイル・道路中心線）を加工して作成。アプリの「その他」→「データの出典と時点」に表示している。
