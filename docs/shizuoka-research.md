# 静岡県・建築基準法上の道路の調べ方

調査日: 2026-11-07。データ本体は `lib/roadmap/data/shizuoka.ts`（下の表はそこから生成）。
ChatGPT などの資料は使わず、市町と県の公式サイト・公式の地図システムを直接開いて確かめた。

## 県の仕組み

- 特定行政庁: 静岡市・浜松市・沼津市・富士市・富士宮市・焼津市。限定特定行政庁: 三島・御殿場・裾野・島田・藤枝・磐田・袋井・掛川・湖西の9市。
  **静岡県では限定特定行政庁の9市も道路種別（指定道路図）を市が扱う**。県の[指定道路図の公開](https://www.pref.shizuoka.jp/kurashikankyo/kenchiku/taishinka/1044596/1015983.html)の表に載るのは土木事務所の管内（残り20市町）だけで、「土木事務所が所管する区域以外は各市の建築担当課へ」とある。
- 土木事務所の管内（指定道路図は窓口で公開）: 下田（下田市・東伊豆町・河津町・南伊豆町）、熱海（熱海市・伊東市）、沼津（伊豆市・伊豆の国市・函南町・清水町・長泉町・小山町）、島田（牧之原市・吉田町）、袋井（菊川市・御前崎市・森町）。電話は県の[特定行政庁の窓口一覧](https://www.pref.shizuoka.jp/kurashikankyo/kenchiku/taishinka/1044597/1015972.html)と各事務所のページで確認（熱海は都市計画課の建築班 0557-82-9191。課の代表 9192 を載せるページもある）。
- 県GIS [静岡県地理情報システム](https://www.gis.pref.shizuoka.jp/?mc=02&mp=101)の「建築基準法上の道路」（mp=101）は、県が所管する区域の参考図。1〜3号は県道・市町道（一部は最新でない）、4号は 2014年3月31日時点、5号・2項・2項（個別指定）・3項に基づく2項道路・特定通路・避難通路は 2021年4月1日時点（地図の更新は 2026-10-23）。geocloud 旧版と同じ `?mp=101&z=18&ll=緯度,経度` で開き、県庁の位置で中心が合うことを iPhone の UA で確認。凡例は `Legend/101-1/101.png`（1号 緑・2号 黄緑・3号 青紫・4号 茶・5号 橙・2項 水色・2項個別 青緑・3項 赤紫・特定通路 赤・避難通路 破線）を書き写した（`scripts/legends/manual.json`）。
- **松崎町・西伊豆町・川根本町は全域が都市計画区域外**（県「[静岡県の土地利用](https://www.pref.shizuoka.jp/_res/projects/default_project/_page_/001/029/763/r5totiriyou.pdf)」の市町別都市計画区域面積（令和4年3月31日現在）で都市計画区域が空欄）。「都市計画区域外」と表示し、道路図は出さない。松崎町・西伊豆町には建築基準法6条1項4号の知事指定区域があるので、建築の扱いは下田土木事務所で確認するよう注記。

## 市ごとの要点

- 静岡市: 市の統合型GIS「[しずマップ](https://city.shizuoka.geocloud.jp/)」（geocloud 新版、2025年1月公開）に「建築基準法上の指定道路情報」（地図 500。レイヤは 3号（官有地・民有地）・4号・5号（民有地）・2項（官有地・民有地）・非道路）と「道路台帳図情報」（地図 600）。`/mp/500?z=18&ll=緯度,経度` で開く。以前の wagmap の「静岡市地図情報インターネット提供サービス」は道路台帳図情報だけになり、2027年3月末で終了予定（同サービスの案内）。市の[地図情報サービス一覧](https://www.city.shizuoka.lg.jp/556_000070.html)の「静岡市指定道路図情報」のリンクは古い wagmap のままなので注意。問い合わせは建築安全推進課 管理係（道路台帳の閲覧 054-221-1371）、道路相談は狭あい道路係 054-221-1238。
- 浜松市: [浜松市地図情報サイト](https://www2.wagmap.jp/hamamatsu/Portal)（wagmap）の指定道路図（mid=65）。市の案内は「2号（一部）・4号・5号・2項と判定道路」だが、レイヤの凡例は 1号〜5号・2項・建築基準法外道路・判定保留道路（都市計画区域内のみ、2026年8月31日時点）。位置指定道路（緑）と民地の2項道路（桃色・赤字の指定番号）は指定時の図面 PDF も開ける。市役所の南で中心一致を確認。建築行政課 053-457-2474、浜名区・天竜区は北部都市整備事務所 053-585-1161（[市の案内](https://www.city.hamamatsu.shizuoka.jp/kensido/douro.html)）。
- 沼津市: [指定道路図](https://www.city.numazu.shizuoka.jp/shisei/office/ichiran/toshikei/jyutakuseisaku/shiteidourozu.htm)は PDF 43枚（2号・3号・4号・5号・2項、2024年3月31日時点）。索引図は画像（`img/shiteidourozu.jpg`）。図ごとの範囲はまだ求めていないので一覧ページを開く（`docs/pdf-sheets.md` の方法で後から図を選べるようにする）。
- 富士市: [ふじタウンマップ](https://www2.wagmap.jp/fujicity/Portal)（wagmap）の指定道路情報（mid=11）。凡例は 42条1項5号道路（位置指定道路）だけ。年1回ほど更新。
- 富士宮市・焼津市・藤枝市: ネット非公開。窓口で指定道路図を閲覧（藤枝市は 2024年5月に県GISから外れた）。
- 三島市: [指定道路図](https://www.city.mishima.shizuoka.jp/page/2249.html)は PDF 38枚（4号・5号・2項、2025年3月14日時点）と凡例・整合表。2026年3月から[三島市地図情報提供システム](https://webgis.alandis.jp/mishima22/portal/index.html)（ALANDIS）に道路台帳図があるが、海外からは接続できず未確認。
- 御殿場市: 2026年3月運用開始の「[ごてんばNAVI](https://www2.wagmap.jp/gotembacity/Portal)」（wagmap）に建築基準法道路（mid=19。凡例は 2号・3号・4号・5号・2項）・道路台帳（mid=14）・道路網図（mid=15）。市役所（萩原）で中心一致を確認。
- 裾野市: [位置指定道路の情報公開](https://www.city.susono.shizuoka.jp/soshiki/6/1/3/6/14762.html)は 5号だけ（PDF 59枚、2026年3月23日時点）。2項道路などは窓口。
- 島田市: [島田市わが街ガイド](https://www2.wagmap.jp/shimada/Portal)（wagmap）に建築基準法上の道路（mid=7。凡例は 1号〜5号・2項・特定通路・法外道路）・道路台帳図（mid=8）。市役所（中央町）で中心一致を確認。
- 磐田市: [いわたGIS](https://www.sonicweb-asp.jp/iwata/agreement?theme=th_11)（Sonicweb）の指定道路情報（建築基準法、th_11）。位置指定道路の図面もダウンロードできる。Sonicweb は海外からの自動確認に 404 を返すため中心一致は未確認（`verified: false`）。
- 袋井市: [指定道路図の公開](https://www.city.fukuroi.shizuoka.jp/soshiki/53/1/tatemono_shinsa/1548400898426.html)は PDF 61枚（1号・2号・3号・5号・2項、2025年3月17日時点。全域図と町名リストで図郭番号を引く）。2026年9月30日から「[どまんなか袋井navi](https://www2.wagmap.jp/fukuroi/Portal)」（wagmap）の道路情報マップ（mid=3）でも建築基準法指定道路図が見られる（路線網図・道路台帳と同じ地図なので「レイヤ表示切替」で切り替える）。電話・FAX・メールでの問い合わせは不可（地図と公図を持って窓口へ）。
- 掛川市: [ｅ－地図かけがわ](https://www2.wagmap.jp/kakegawa/Portal)（wagmap）に建築基準法指定道路マップ（mid=16。凡例は 1号・2号・3号・5号・2項）・市道認定路線マップ（mid=17）。相談はくらしデザイン課 建築営繕係 0537-21-1152（[市の案内](https://www.city.kakegawa.shizuoka.jp/gyosei/docs/9827.html)）。地図の内容は都市政策課。
- 湖西市: [GISこさい](https://arcg.is/0nLvv8)（ArcGIS Experience Builder）の「地図 道路 建築基準法第42条」ページ（page_40、地図ウィジェット widget_950）。公開のフィーチャレイヤ `kentikukijyunho_42jyo_kiteidoro`（属性 `a_type` ＝ 法42条1項1号・2号・3号・5号・2項、3,512本）を読んで、物件のまわりの道路の種別を文字で出す。線は1色なので色では見分けられない。最初に利用規約の同意にチェックして OK。
- 菊川市: 県（袋井土木事務所）の所管だが、市の「[きくのんマップ](https://www2.wagmap.jp/kikugawa/Portal)」（wagmap）に建築基準法道路（mid=5。凡例は 1号・3号・5号・2項・特定通路）と市道認定路線網図（mid=11）がある。市の地図を先に、県GISも開く。

## 残り（次にやること）

- 沼津・三島・裾野・袋井の PDF 分割図は、図ごとの範囲（`lib/roadmap/data/sheets/`）を求めて物件の図を直接開けるようにする。
- 磐田市（Sonicweb）の中心一致と、三島市の ALANDIS の入口は、日本国内の回線で確かめる。
- 浜松市の路線認定図・現況平面図（wagmap の別の地図）の地図番号。
