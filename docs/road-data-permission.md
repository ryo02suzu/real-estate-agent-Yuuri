# 役所の道路種別のデータを MICHILU の中に表示するための確認と許可

2026-11-13 にまとめたもの。

## どういう話か

役所の道路種別の地図のうち、データを外から読める作りのもの（ArcGIS の公開レイヤ）は、
MICHILU の地図に種別の色で描いたり、「北 約6m：2項道路」のように文字で出したりできる（`lib/roadmap/road-read.ts`）。
役所のページを開かずに済むので便利だが、**データを読めることと、使ってよいことは別**。
各サイトの利用規約の全文を読んだところ、ほとんどが「無断の複製・転載」「営利目的の利用」を禁じていた。

そこで、アプリの中に表示するのは、**使ってよいと確かめた市区町村だけ**にした
（`lib/roadmap/road-read-permission.ts` の `ROAD_READ_PERMITTED`）。
それ以外の市区町村は、今までどおり公式の地図を物件の位置で開く（リンクは各規約で認められている）。

読み方の設定（`data/<県>.ts` の `read`）は消していない。
許可をもらったら、`ROAD_READ_PERMITTED` に市区町村コードを1行足せば、その市の表示が戻る。

## 役所にお願いするときの文面（ひな形）

> 件名：貴市の道路種別の地図データの利用について（お願い）
>
> 〇〇市 〇〇課 御中
>
> 不動産の調査に使う Web アプリ「MICHILU（ミチル）」を運営している〇〇と申します。
> 貴市が公開されている「〇〇（地図の名前）」について、次の使い方をお認めいただけないか、お伺いします。
>
> 1. 使い方：利用者が調べた土地のまわり（約50m）の道路の種別を、貴市の公開の地図データから読み、
>    アプリの地図に貴市の凡例の色で表示します。データはその都度、利用者の端末から貴市の公開サービスへ
>    直接読みに行き、当方のサーバーには保存しません。
> 2. 表示の内容：貴市の地図に載っている種別だけを、そのまま表示します。前面道路かどうか・接道の可否などの
>    判断は表示しません。「参考図であり、最終確認は窓口で」と、貴市の窓口の連絡先を必ず添えます。
> 3. 出典：「〇〇市「〇〇」より」と、データの時点を画面に表示します。貴市の地図へのリンクも置きます。
> 4. 料金：アプリは（無料／有料）で提供します。貴市のデータそのものを販売することはありません。
>
> 条件（出典の書き方・注意書きなど）がありましたら従います。難しい場合は、その旨お知らせいただければ、
> 今までどおり貴市の地図を開くリンクだけにいたします。
> どうぞよろしくお願いいたします。

許可をもらったら、日付・相手・条件を `ROAD_READ_PERMITTED` の `basis` に書き、条件どおりの出典を `credit` に書く。
