- 特定行政庁は福井県と福井市だけ。県の「[建築確認申請、完了（中間）検査申請の受付窓口について](https://www.pref.fukui.lg.jp/doc/kenchikujyuutakuka/madoguchihenkou.html)」（2026年3月17日更新）の表: 永平寺町 → 福井土木事務所 建築営繕課 0776-24-5179、坂井市・あわら市 → 三国土木事務所 建築課 0776-82-1110、大野市・勝山市 → 奥越土木事務所 建築課 0779-66-8138、越前市・池田町・南越前町 → 丹南土木事務所 建築課 0778-23-4538、鯖江市・越前町 → 丹南土木事務所 鯖江丹生土木部 建築課 0778-34-0465、敦賀市・美浜町・若狭町（旧三方町の地域） → 嶺南振興局 敦賀土木事務所 建築課 0770-22-5486、若狭町（旧上中町の地域）・小浜市・高浜町・おおい町 → 嶺南振興局 小浜土木事務所 建築課 0770-56-5914、福井市 → 福井市役所 建設部 建築指導課 0776-20-5574（特定行政庁）。若狭町は場所で窓口が分かれるので、問い合わせ先は敦賀にして、旧上中町は小浜と添えた。
- **県の指定道路マップ**: 「[建築基準法に基づく位置指定道路の位置情報の公開（福井県指定道路等閲覧システム）について](https://www.pref.fukui.lg.jp/doc/kenchikujyuutakuka/ichishiteikoukai.html)」（2023年4月3日更新）で、「県がこれまでに位置の指定をした道路【位置指定道路】の位置情報を公開します」として「[福井県指定道路等閲覧システム](https://www2.wagmap.jp/fukuidouro/)」（wagmap `fukuidouro`）。福井市の指定道路は福井市長が指定しているので載らない。地図「指定道路」（mid=1）は土木事務所ごとの「42条1項5号_福井」〜「42条1項5号_小浜」（同じ橙）と「福井市は対象外」のレイヤで、凡例は「42条1項5号」1つにまとめた（`scripts/legends/build.py` に、全部の項目が「同じ種別_○○」で同じ色のときだけまとめる決まりを足した。ほかの地図の凡例は変わらない）。利用条件の同意の後、坂井市役所・敦賀市役所の位置に開き、位置指定道路の線が出ることを画面で確認。県が扱う16市町は「一部」（5号だけ）。
- **都市計画区域の無い町**: 同じページの窓口の表に「［］は都市計画区域および準都市計画区域がないので位置指定道路はありません」とあり、［南越前町］［池田町］［おおい町］。「都市計画区域外」と表示し、道路図は出さない。永平寺町は［］が付かず位置指定道路がある町で、県の「[都市計画区域等の白地地域の建築形態規制について](https://www.pref.fukui.lg.jp/doc/kenchikujyuutakuka/siraji.html)」にも永平寺準都市計画区域がある。
