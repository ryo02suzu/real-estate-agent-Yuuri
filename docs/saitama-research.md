# 埼玉県・建築基準法上の道路の調べ方（全63市町村）

調査日: 2026-09。データ本体は `lib/roadmap/data/saitama.ts`（下の表はそこから生成）。

## 前提

- **全40市と杉戸町・松伏町は、道路種別を各市町が扱う**。残り20町と東秩父村は県（建築安全センター・駐在）が扱う（[県 建築行政の窓口](https://www.pref.saitama.lg.jp/a1106/madoguti/madogutiannai.html)）。
- 県は20町の指定道路図を ArcGIS で公開している（42条1項1号〜5号・2項・4項・予定道路の全種別。[県ページ](https://www.pref.saitama.lg.jp/a1106/kenntikuhudousann/kentikukizyunnhounikannsurukoto/04dai3syoutosikeikakukuikitouniokerukenntikubutunosikitikouzoukenntikusetubioyobiyouto/42zyousiteidourozunoho-mupe-zikoukai.html)）。東秩父村は含まれない。
- 「公道か（道路台帳・認定路線）」と「建築基準法上の道路か（指定道路図）」は**別の地図**。再建築可否に効くのは後者。
- 市区町村コードは国土地理院の逆ジオコーダが返すもの。`lib/roadmap/data/gsi-muni-codes.json` と照合するテストで、全63市町村（さいたま市は10区）が漏れなく登録されていることを確認している。

## 再確認（2026-09 二回目）

「一部のみ」「ネット非公開」とした市町を、国交省の公開状況一覧（R5.4.1）・各市のWeb地図のメニュー・市の案内ページで一つずつ確かめ直した。

- **狭山市 → 全種別**。Sonicweb「指定道路図」テーマ（th_3）で道路種別レイヤ（th_5）を最初から表示させる `&layers=dm%2Cth_5` で、市役所の位置に全種別が出ることを確認。
- **春日部市 → 全種別**。かすかべオラナビ `/mp/81`「建築基準法上の道路種別」（iPhone の UA で確認）。色の無い道は窓口で確認。
- **蓮田市 → 一部**。Sonicweb th_10「指定道路図」。凡例は 42条1項1〜5号のみで 2項道路は無い（同意画面は「はい」）。
- **戸田市**: 道路路線図（認定幅員つき）を座標で開けるようにした（`e-toda.kukanjoho.jp/mp/401`）。市道・幅員4m以上なら1項1号という市の案内に使える。位置指定道路は非公表。
- **加須・入間**: 市道の地図（かぞまっぷ 道路台帳図、認定路線マップ）を参考として追加。道路種別の地図は無い（wagmap 全マップのレイヤ名を確認）。
- **引き続き非公開と確認**: 川越・所沢・草加・久喜・入間・三郷・深谷・鴻巣・ふじみ野・加須・坂戸・行田・秩父・東松山・羽生・蕨・北本・幸手・鶴ヶ島・日高・吉川・白岡・杉戸・松伏・東秩父。国交省一覧に載っておらず、市のWeb地図（wagmap・Sonicweb・geocloud・alandis・geogeo）にも道路種別のメニューが無い。草加・所沢・久喜・戸田は市のページで「窓口（または電話・依頼書）で確認」と明記。
- 熊谷・本庄・さいたま・桶川・飯能・新座・富士見は位置指定道路（や道路台帳）までで、2項道路は載っていない（変更なし）。

## 地図システム別のURL形式（`lib/roadmap/vendors.ts`）

| システム | 自治体 | 座標の渡し方 | 注意 |
|---|---|---|---|
| wagmap | 越谷・上尾・熊谷・川越・本庄・朝霞・鶴ヶ島ほか | `Map?mid=&mpx=経度&mpy=緯度&gprj=2` | **gprj=2（WGS84）必須**。付けないと地図の測地系（旧日本測地系が多い）のまま解釈され約450mずれる。サーバが返す初期座標で、全地図が gprj=2 を変換することを確認（gprj=3 は厚木・小田原・茅ヶ崎で無視される） |
| Sonicweb | さいたま・狭山・蓮田 | `pos=経度,緯度`（`&layers=` で表示レイヤ指定） | 世界測地系 |
| alandis | 飯能市 | `x=,y=`（EPSG:3857 のメートル）`&rs=3857` | 地図の「地図URL」機能と同じ形式 |
| cloudgis (gauandy) | 桶川市 | `?lon=&lat=&z=` | |
| open-map.jp | 八潮市 | `#lat=&lng=&z=&layers=レイヤ名` | 同意ページが hash を地図へ引き継ぐ |
| geocloud | 川口・春日部・戸田 | 旧 `webgis/?ll=緯度,経度&z=` ／ 新 `/mp/<ID>?z=&ll=緯度,経度` | 自動ブラウザは 403。iPhone の UA で確認 |
| ArcGIS Experience Builder | 県（20町） | `#widget_34=center:経度,緯度,4326,scale:` | Esri の公式パラメータ形式。検証環境ではアプリが起動せず未確認 |

## 注意

- 自治体GISの規約には「不動産取引のための資料として用いることはできません」とあるもの（世田谷区など）がある。**アプリは地図を開くだけ・最終確認は窓口**という位置づけを崩さないこと。
- ふじみ野市で検索に出る ArcGIS「指定道路マップ」（98e34509…）は**八王子市のもの**（所有者 hachiojiadmin）。使わないこと。
- 電話で答えない市町（所沢・春日部・深谷・鴻巣・飯能）は `noPhoneInquiry` で発信ボタンを出さない。
