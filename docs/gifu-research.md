# 岐阜県・建築基準法上の道路の調べ方

調査日: 2026-11-07。データ本体は `lib/roadmap/data/gifu.ts`（下の表はそこから生成）。
ChatGPT などの資料は使わず、県と市町村の公式サイト・公式の地図システムを直接開いて確かめた。

## 県の仕組み

- 特定行政庁は岐阜県と岐阜市・大垣市・各務原市。限定特定行政庁（小さな建築物だけ市が確認）は高山市・多治見市・可児市。残りの36市町村は県の建築事務所が扱う（県の[県内の特定行政庁](https://www.pref.gifu.lg.jp/page/8347.html)）。
- 県の建築事務所は4つ（2013年度に岐阜と西濃が統合）。[岐阜・西濃建築事務所](https://www.pref.gifu.lg.jp/soshiki/26119/)（大垣市江崎町422-3 西濃総合庁舎3階、0584-73-1111 内線384 岐阜地区係・387 西濃地区係。羽島市・山県市・瑞穂市・本巣市・海津市・羽島郡・養老郡・不破郡・安八郡・揖斐郡・本巣郡）、[中濃建築事務所](https://www.pref.gifu.lg.jp/soshiki/26122/)（美濃加茂市 可茂総合庁舎、0574-25-3111 内線332・333。関市・美濃市・美濃加茂市・可児市・郡上市・加茂郡・可児郡）、[東濃建築事務所](https://www.pref.gifu.lg.jp/soshiki/26120/)（多治見市 東濃西部総合庁舎、0572-23-1111 内線332・333 建築指導係。多治見市・中津川市・瑞浪市・恵那市・土岐市）、[飛騨建築事務所](https://www.pref.gifu.lg.jp/soshiki/26121/)（高山市 飛騨総合庁舎分館2階、0577-33-1111 内線391・392 建築指導係。高山市・飛騨市・下呂市・大野郡）。
- 前面道路の種別は、県が扱う市町村でも市町村の建築担当課が窓口で、2項道路は建築事務所と市町村が共同で調べる（[中濃建築事務所のよくある質問](https://www.pref.gifu.lg.jp/page/13779.html)）。問い合わせ先は県の[市町村の建築担当の窓口の表](https://www.pref.gifu.lg.jp/page/3764.html)（2025年4月1日）から取った。
- 県も市町村も「指定道路図」はネットに出していない。道路種別の地図があるのは可児市だけ（下記）。市道の認定路線図・道路台帳は、県と市町村が共同で運用する県域統合型GIS「ぎふ」か PDF で公開する市町が多い。
- **県域統合型GIS「ぎふ」**（[gis-gifu.jp](https://gis-gifu.jp/gifu/Portal)）は wagmap と同じ仕組み。`Map?mid=<地図ID>&mpx=経度&mpy=緯度&mps=2500&gprj=3` で開くと利用条件の同意ページ（302）→同意→その地図に戻る。可児市・岐阜市の公式リンクも同じ `gprj=3` の形。自動ブラウザで、同意後の地図画像の要求（`GetMapImage … cp=137.0610,35.4260`）が渡した座標そのものになること、可児市の地図（1/2,500）で中心の十字が可児市役所に重なり画面の座標表示も一致することを確かめた。1/1,000 はタイルが無い地図があるので既定は 1/2,500。サーバの暗号設定が古く（DH 鍵が小さい）、curl と凡例スクリプトは `SECLEVEL=1` 以下で接続する。ポータルの一覧（`oConfig`）に全401地図があり、市道の地図は 岐阜市認定路線網図(20008)・大垣市道路台帳図(429)・各務原市道路台帳(12105)・関市道路台帳(3000)・中津川市道路台帳網図(5003)・瑞穂市道路認定路線網図(3400)・揖斐川町道認定路線網図(2402)・富加町道路台帳(3600)・可児市道路台帳図(20010)、道路種別は「可児市 建築基準法上の道路種別」(11017)。「道路台帳附図」(3610) は県の道路台帳オープンデータ（県道）なので使わない。
- **cloud-gis.jp**（羽島市・本巣市・美濃加茂市）は利用規約のページで同意の欄にチェックして地図のボタンを押すと `inet.php?f=<地図ID>&zlimit=` に移る仕組みで、URL に座標を付けられず、直接開くと空のページになる。愛知県の瀬戸市と同じく入口のページだけ添える（⚠️）。
- **全域が都市計画区域外**: 七宗町・白川町・東白川村（中濃建築事務所の案内）、白川村（[飛騨建築事務所の都市計画区域外の確認申請の案内](https://www.pref.gifu.lg.jp/uploaded/attachment/423602.pdf)に「白川村：全域」）。県の[都市計画区域マスタープラン](https://www.pref.gifu.lg.jp/page/2433.html)の31区域にもこの4町村は無い。一部が区域外なのは高山市（荘川町・一之宮町・久々野町・朝日町・高根町・上宝町・奥飛騨温泉郷）、飛騨市（河合町・宮川町の全域と古川町・神岡町の一部）、下呂市（小坂町・馬瀬の全域と旧下呂町・萩原町・金山町の一部。以上は同じ案内）、関市・郡上市・八百津町（中濃建築事務所の案内）。

## 市ごとの要点

- 岐阜市: 道路位置指定と道路調査は[建築指導課 指導係](https://www.city.gifu.lg.jp/info/soshiki/1010534/1010538.html)（市庁舎17階、058-214-2428）。[市道路線の路線名および路線番号](https://www.city.gifu.lg.jp/kurashi/douro/1002472/1002473.html)から県GISの認定路線網図（20008）が開けるが「道路幅員については確認することができません」。市道の認定は土木調査課（16階、調査計画係 058-214-7075）で、電話だけでは答えず案内図や公図を送って確認。市の[県域統合型GISの一覧](https://www.city.gifu.lg.jp/info/onlineservice/1009513.html)に道路種別の地図は無い。
- 大垣市: [道路台帳図](https://www.city.ogaki.lg.jp/0000046570.html)（県GIS 429）は路線番号と路線名だけで「道路幅員は閲覧することができません」（管理課の窓口で）。建築基準法上の道路の種類は[建築指導課](https://www.city.ogaki.lg.jp/soshiki/11-7-0-0-0_11.html)（市役所5階、建築指導グループ 直通 0584-47-8436）。
- 各務原市: [道路台帳の閲覧](https://www.city.kakamigahara.lg.jp/business/tochi/1009074/1019557.html)（県GIS 12105、路線網図と幅員。建設管理課 058-383-1904）。[建築指導課](https://www.city.kakamigahara.lg.jp/shisei/soshiki/1006500/1006507.html)は市役所5階 058-383-1482（審査係が建築基準法）。
- 高山市: [道路の幅と名称](https://www.city.takayama.lg.jp/faq/1000079/1000191/1003673.html)は維持課（0577-35-3340）か支所の窓口で道路台帳を見る。「電話による照会は、間違いの原因となりますので、窓口での確認をお願いします」。
- 多治見市: [建築基準法のページ](https://www.city.tajimi.lg.jp/kurashi_tetsuduzuki/machizukuri/1005830/1005851/1005853.html)の担当は開発指導課 建築指導グループ 0572-22-1336。道路台帳の公開は見つからず。

## 残り（次にやること）

- 県GISの地図は、この環境からタイル画像（scr.wagmap.jp）が取れなかったので、中心一致は地図画像の要求パラメータと可児市（1/2,500）の画面で確かめた。岐阜市（20008）など他の地図も同じ仕組み。日本国内の回線で開いて再確認する。
- cloud-gis（羽島・本巣・美濃加茂）は座標付きで開けない。地図の中で住所検索する。
- 町村の道路台帳の公開は個別に確認していない所が多い。
