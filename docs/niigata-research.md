# 新潟県・建築基準法上の道路の調べ方

調査日: 2026-11-07。データ本体は `lib/roadmap/data/niigata.ts`（下の表はそこから生成）。
ChatGPT などの資料は使わず、県と市町村の公式サイト・公式の地図システムを直接開いて確かめた。

## 県の仕組み

- 特定行政庁（独自に建築主事を置く市）は新潟市・長岡市・上越市・柏崎市・三条市・新発田市の6市。残りの24市町村は県の地域振興局 地域整備部 建築課が扱う（県の[建築課の所管区域](https://www.pref.niigata.lg.jp/sec/jutaku/1197216943238.html)。電話もこのページ）: 新発田（0254-26-9199。村上市・阿賀野市・胎内市・聖籠町・関川村・粟島浦村）、新潟（025-273-3204。五泉市・阿賀町）、三条（0256-36-2319。加茂市・燕市・弥彦村・田上町）、長岡（0258-38-2625。小千谷市・見附市・出雲崎町・刈羽村）、南魚沼（025-772-3958。十日町市・魚沼市・南魚沼市・湯沢町・津南町）、上越（025-526-9529。糸魚川市・妙高市）、佐渡（0259-74-3339。佐渡市）。
- 県は指定道路図をネットに出していない。指定道路調書は建築計画概要書と同じく地域振興局の建築課で閲覧する（[新発田地域振興局 建築課](https://www.pref.niigata.lg.jp/sec/shibata_seibi/shibata-kenchiku.html)の案内）。
- **都市計画区域が無い町村**: 出雲崎町・津南町・刈羽村・関川村・粟島浦村（県の[開発許可について](https://www.pref.niigata.lg.jp/sec/toshiseisaku/1191256257277.html)の開発許可権者一覧（2026年3月1日現在）で都市計画区域が「－」。県内は24の都市計画区域）。「都市計画区域外」と表示し、道路図は出さない。
- **geogeo（ジオジオ）の公開型GIS**を使う市が多い（にいがたeマップ・eマップじょうえつ・新発田市市民公開地理情報システム・eまっぷいといがわ・魚沼市地理情報システム・e-みょうこうマップ・十日町市と南魚沼市の公開地理情報システム）。地図は Mapbox GL で、`/maps?mode=theme&lid=<大分類>&mid=<テーマ>&lat=緯度&lng=経度&z=17` で開く（`themes/themes.json` にテーマ一覧、`themes/getlayers.json?mid=` にレイヤ一覧と凡例の色）。**経度の名前は `lng`**：はじめは `lon` で作り、市役所の位置で中心に来ることを確かめていたが、テーマの最初の位置もそれぞれの市役所のあたりだったため、`lon` が読まれていないことに気づけなかった。2026-11-09 に一関市の地図で市役所から離れた地点を開いて比べ（`lng` ならその地点にピンが立って中心に来る、`lon` だと市役所のまま）、この県の geogeo の地図すべて（十日町市・南魚沼市の独自ドメインも）で `lng` のときだけページの `init_mode` が `latlng` になることを確かめて `lng` に直した。利用規約のあるテーマ（にいがたeマップの「道路」、新発田の両方、上越の「道路・建設」）は最初に同意の画面が出る。レイヤの表示切替は URL では指定できない（妙高の `ol=` は効かなかった）。十日町市の地図は https の証明書がホスト名と合わないので http で開く。

## 市ごとの要点

- 新潟市: 道路種別の地図は無く、[建築基準法の道路について](https://www.city.niigata.lg.jp/kurashi/jyutaku/kenchiku/kenchikudoro/kenchikudoro.html)のとおり建築行政課に照会する。[建築行政課](https://www.city.niigata.lg.jp/shisei/soshiki/soshikiinfo/kenchiku/kenchikugyosei.html)（古町ルフル6階）の監察指導係（025-226-2845）が建築基準法の道路の担当で、照会は窓口・FAX（025-229-5190）・メール（kenchiku@city.niigata.lg.jp）。「[建築基準法に規定する道路種別に関する判別・照会について](https://www.city.niigata.lg.jp/kurashi/jyutaku/kenchiku/tetsuduki/doro_index/dorosyokai.html)」に「電話では場所を間違ってしまう恐れがあるため受け付けていません」とある（このページは海外からの取得では見つからず、検索エンジンの要約で確認。国内で再確認する）。位置指定道路は[位置指定道路を調べたい](https://www.city.niigata.lg.jp/kurashi/doro/road/dorochosa/ichishiteidoro/index.html)から「にいがたeマップ」の指定道路情報（テーマ 15、レイヤは法第42条第1項第5号だけ）。「道路」（テーマ 9）に国道・県道・市道の区分と道路台帳、テーマ 16・17 に道路台帳平面図の図郭割図。
- 長岡市: [建築基準法上の道路とは](https://www.city.nagaoka.niigata.jp/kurashi/life03/douro-iti.html)から「[ながおか便利地図](https://www.city.nagaoka.niigata.jp/shisei/cate08/jyouhouka/benri-map.html)」（wagmap）の道路情報（mid=181）。レイヤは 2号道路（開発行為）・3号道路（既存道路）・2項道路・2項道路（3項に基づく水平距離が指定された部分）・5号道路（位置指定道路）と市道網図で、1号（国道・県道・市道）と4号は無い。凡例はレイヤ一覧から自動で取る。「該当しない場合や表示がない道については建築・開発審査課にお問い合わせください」（大手通庁舎、0258-39-2226）。
- 上越市: [建築住宅課](https://www.city.joetsu.niigata.jp/soshiki/kenjuu/)の指導係（025-520-5783）が「建築基準法に基づく許可、認定、道路の取扱い等」。「[eマップ じょうえつ](https://www.city.joetsu.niigata.jp/soshiki/gyoukaku/emapjoetsu.html)」（geogeo、2022年11月開始）の「道路・建設」（lid=2, mid=20）に市道網図・位置指定道路・道路台帳横断面図（旧上越市）・法22条区域のレイヤ。[市道網図等の閲覧](https://www.city.joetsu.niigata.jp/soshiki/douroka/shidou-mouzu.html)は道路課（025-520-5769）。
- 柏崎市: [まちナビで建築基準法の指定道路と指定道路調書を公開します](https://www.city.kashiwazaki.lg.jp/soshikiichiran/toshiseibibu/kenchikujutakuka/4/2/1/6189.html)（位置指定道路と2項道路。道路を押すと指定道路調書 PDF。建築住宅課 審査係 0257-21-2291）。[まちナビ柏崎](https://www.city.kashiwazaki.lg.jp/soshikiichiran/sogokikakubu/kikakuseisakuka/2/1/6754.html)の「道路」は ArcGIS の Instant Apps（ポートフォリオ）で、中の「指定道路図」は Experience Builder のアプリ（0e686a1a…、地図ウィジェット widget_6）、「柏崎市道」は Web AppBuilder のアプリ（4349877834…）。どちらも柏崎市役所の位置で中心が合うことを確認。凡例は Web マップのレイヤの描画設定（位置指定道路 #ffaa00、法第42条2項道路 #00c5ff）。
- 三条市: [道路に関すること](https://www.city.sanjo.niigata.jp/kurashi_tetsuzuki/machizukuri/sumai_doro/8928.html)のとおり、市道は建設課 建設管理係（0256-34-5717）、4m未満の道・位置指定は建築課 審査指導係（0256-34-5727。位置指定は位置図と公図を持って窓口へ、原則電話では答えない）、都市計画道路は建設課 計画整備係（0256-34-5714）。[三条市都市計画情報公開システム](https://www.city.sanjo.niigata.jp/soshiki/kensetsubu/kensetsuka/keikakuseibi/sanjo_toshikeikaku/14889.html)（ArcGIS Hub）に2023年12月から道路台帳平面図（三条地域、栄・下田地域の一部）。座標付きで開く入口は見つからず、ポータルだけ添える。
- 新発田市: [市民公開地理情報システム](https://www.city.shibata.lg.jp/machidukuri/joho/chiri/1002426.html)（geogeo）に位置指定道路情報（lid=1, mid=11）と市道情報（mid=8。道路網図は豊浦・加治川地区）。建築基準法上の種別は[建築課 建築審査係](https://www.city.shibata.lg.jp/kurashi/sumai/taterutoki/1001254.html)（地域整備庁舎2階、0254-26-3557）。
- 妙高市（県が扱う）: [統合型地理情報システム](https://www.city.myoko.niigata.jp/docs/25.html)「e-みょうこうマップ」の「道路」（lid=1, mid=6）に道路位置指定図・建基法第42条2項道路図のレイヤ（最初は非表示）。
- 糸魚川市: [建設敷地の諸条件を調査](https://www.city.itoigawa.lg.jp/page/1529.html)の「eまっぷいといがわ」の道路・建設（lid=5, mid=15）に国県道網図・市道網図（種別は国県道/市道の区分）。
- 魚沼市: [市道路線をwebで確認できます](https://www.city.uonuma.lg.jp/page/2271.html)（geogeo、認定路線。幅員は無し）。南魚沼市・十日町市: 公開地理情報システム（geogeo）の「道路」に市道認定路線・市道網図。
- 見附市: [みつけマップ](https://www.city.mitsuke.niigata.jp/soshiki/2/2189.html)（ArcGIS Hub）の市道路線網マップは Web AppBuilder のアプリ（51158390…）で、center= で見附市役所の位置に開く（最初に利用条件に同意）。
- 小千谷市（[道路網図](https://www.city.ojiya.niigata.jp/soshiki/kensetsu/douromouzu.html) PDF 31枚）・五泉市（[道路網図](https://www.city.gosen.lg.jp/organization/14/7/2/859.html) PDF 6枚と路線名一覧）・阿賀野市（[市道網図](https://www.city.agano.niigata.jp/soshiki/kensetsuka/doro_kotsu/2391.html) PDF 5枚）は分割図の入口を添える。
- 燕市（つばめNavi、wagmap）に道路の地図は無い。村上市・佐渡市・加茂市・胎内市と町村は市道の地図のネット公開が見つからなかった。
