## 6. 残りの作業（別セッションで続けられるように）
1. **実ブラウザの確認**（`qa/michilu-ui-v2-review` のブラウザ検証。このブランチはそちらを触らない）：特に、日本地図が実際に見えるか（§5c の M1 を直したので、前の Preview とは見え方が変わるはず）、ドラッグの追従と本文のスクロールの干渉、iPhone のキーボード、端末の「戻る」（詳細→全画面の地図→一覧→ホーム）、シートのフォーカスと読み上げ、44px の押せる範囲、各画面幅、PC の画素の一致。
2. **横向きのホーム**：パネルが高さの約9割を覆うので、日本全体はほとんどパネルの裏になる（画面の外へ飛ぶ・[0,0] に残る不具合は直した）。iPhone の横向きは、パネルを左に寄せる（地図アプリのような横の配置）か、ホームの高さを抑えるかを、実画面を見て決める。
3. `npm run check-tiles`（ネットにつながる環境）で、低ズームのタイルを Origin 付きで確かめ直す。
4. 詳細の中の小さいリンク（注記の「くわしく」、地図の小さいボタン、路線価のリンクなど）の押せる範囲は一部そのまま。
5. 200% 文字：文字の大きさが `px` 指定のため、端末の文字拡大にどこまで追従するかは未確認。
