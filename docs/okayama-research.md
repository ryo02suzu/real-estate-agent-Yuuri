# 岡山県・建築基準法上の道路の調べ方

## 県の仕組み

- **受け持ち**：県「[確認申請等の相談窓口と担当エリア](https://www.pref.okayama.lg.jp/page/detail-31594.html)」。「確認申請・完了検査等の相談窓口はすべて県民局」「電話での問い合わせも以下の相談窓口あてに」「窓口での相談を希望される方は、あらかじめ窓口にご連絡のうえ来局」。県民局の担当に「建築基準法に関する相談、道路調査、手続等」。
  - 備前県民局 建設部管理課 建築指導班（岡山市北区弓之町6-1・086-233-9847）：備前市・瀬戸内市・赤磐市・和気町・吉備中央町
  - 備中県民局 建設部管理課 建築指導班（倉敷市羽島1083・086-434-7160）：井原市・高梁市・浅口市・早島町・里庄町・矢掛町
  - 美作県民局 建設部管理課 建築指導班（津山市山下53・0868-23-1260）：真庭市・美作市・鏡野町・美咲町・久米南町・新庄村・勝央町・奈義町・西粟倉村
  - 特定行政庁の各市：岡山市（都市整備局建築指導課）・倉敷市（建設局建築部 建築指導課）・津山市（都市建設部 都市計画課）・玉野市（建設部 都市計画課）・笠岡市（建設部 都市計画課）・総社市（建設部 建築住宅課）・新見市（建設部 都市整備課）
- **備中県民局の FAX**（086-423-4043）は、「[備中県民局電話番号一覧](https://www.pref.okayama.lg.jp/site/12/detail-45625.html)」の建設部 管理課 建築指導班の欄。備前・美作の建築指導班の FAX は、確かめたページに建築指導班のものとして書かれていないので入れていない。

## 道路種別の確かめ方

- 県の道路種別の地図（指定道路図など）は、ネットに見つからなかった。
- 県「[建築基準法等に関するよくある質問・回答](https://www.pref.okayama.lg.jp/uploaded/life/1048703_10155006_misc.pdf)」（岡山県管轄分）：
  - 「建築基準法上の道路種別（法第42条第2項道路等）の確認はどこでできますか。」→「管轄の県民局建設部管理課建築指導班の窓口で確認が可能です。道路の位置が特定できる地図等を、窓口に持参いただくか、ファックス等でお問合せ下さい。都市計画区域外の場合、法第43条の接道義務はありませんので、法第42条第２項道路等はありません。」
  - 「幅員４ｍ以上の市道について、建築基準法上の道路種別を教えて下さい。」→「道路法による道路（国道、県道、市町村道）で、原則として、交差点から交差点間の全長にわたり、幅員が４ｍ以上ある場合は、法第42条第１項第１号道路に該当します。」

## 都市計画区域

国の[令和7年都市計画現況調査](https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000217.html)の都市別一覧（令和7年3月31日現在）で、岡山県は21市町に都市計画区域がある。**無いのは瀬戸内市・新庄村・奈義町・西粟倉村・久米南町・美咲町の6つ**。全域が都市計画区域なのは早島町・里庄町・矢掛町で、ほかは一部。
