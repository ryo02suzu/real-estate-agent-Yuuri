# 山梨県・建築基準法上の道路の調べ方

調査日: 2026-11-07。データ本体は `lib/roadmap/data/yamanashi.ts`（下の表はそこから生成）。
ChatGPT などの資料は使わず、県と市町村の公式サイト・公式の地図システムを直接開いて確かめた。

## 県の仕組み

- 特定行政庁は山梨県と甲府市だけ（県の[建築基準法運用基準](https://www.pref.yamanashi.jp/documents/82663/kenchikukijunhouunoukijun.pdf)）。富士吉田市の限定特定行政庁は[2015年3月31日で廃止](https://www.pref.yamanashi.jp/kenchikujutaku/sinsa/fujiyoshida.html)。甲府市以外の26市町村の道路種別は県の建設事務所が扱う。
- 建設事務所の管内と電話（県の[道路位置指定のページ](https://www.pref.yamanashi.jp/kenchikujutaku/sinsa/ichisiteidouro.html)の表）: 中北建設事務所 建築課 055-224-1674（甲斐市・南アルプス市・中央市・昭和町・韮崎市・北杜市）、峡東建設事務所 都市計画・建築課 0553-20-2718（山梨市・笛吹市・甲州市）、峡南建設事務所 都市計画・建築課 055-240-4133（市川三郷町・早川町・身延町・南部町・富士川町。[事務所のページ](https://www.pref.yamanashi.jp/kn-kensetsu/58101577242.html)では建築住宅担当の番号）、富士・東部建設事務所 都市計画・建築課 0554-22-7817（富士吉田市・大月市・都留市・上野原市・道志村・西桂町・忍野村・山中湖村・鳴沢村・富士河口湖町・小菅村・丹波山村）。
- 県GIS「[まっぷDE山梨](https://gis.pref.yamanashi.jp/webgis/?p=1)」（geocloud 旧版）に「建築基準法指定道路図」が建設事務所ごとの4つの地図で載る（峡東 mp=500-61、峡南 501-31、中北 502-125、富士・東部 503-67。ポータルの一覧のリンクから）。凡例は4地図とも 4号道路（橙）・5号道路（黄）・2項道路（水色）だけ（`Legend/502-125/502.png`）。URL は `?mp=502-125&bt=0&z=18&ll=緯度,経度` の形（川口市などの geocloud 旧版と同じ）だが、地図の画面は海外からの自動ブラウザに空の応答（HTTP 202）を返すため、中心一致は確認できていない（`verified: false`）。
- **全域が都市計画区域外**: 北杜市・早川町・南部町・道志村・鳴沢村・小菅村・丹波山村。県の[都市計画区域マスタープラン](https://www.pref.yamanashi.jp/toshikei/h23kuikimasu_sakutei.html)の12区域（甲府：甲府市・甲斐市・中央市・昭和町、峡東：山梨市・甲州市、韮崎：韮崎市・甲斐市、南アルプス：南アルプス市、笛吹川：甲府市・笛吹市・中央市、市川三郷：市川三郷町・富士川町、富士川：富士川町（以上は[甲府盆地7区域の計画書](https://www.pref.yamanashi.jp/documents/36696/kouhukuikimasu_2.pdf)）、富士北麓：富士吉田市・西桂町・忍野村・山中湖村・富士河口湖町、都留・大月・上野原・身延）に入らない。県の[都市計画マスタープラン](https://www.pref.yamanashi.jp/documents/31286/4dai3shou.pdf)でも「都市計画区域外：道志村、鳴沢村、小菅村、丹波山村」「北杜市、早川町、南部町」と書かれている。「都市計画区域外」と表示し、道路図は出さない。

## 市ごとの要点

- 甲府市: 道路種別の地図はネット非公開。[建築指導課の案内](https://www.city.kofu.lg.jp/k078/p003289.html)のとおり「道路相談カード」と案内図・公図の写し・現況図を持って本庁舎7階の窓口へ（回答は通常2週間程度、長い道は約1か月）。審査係 055-237-5824。市の公開型GIS「[こうふMAP](https://kofu.geocloud.jp/)」（geocloud 新版）に市道認定路線情報（地図 329）と道路台帳平面図（地図 339）があり、`/mp/329?z=18&ll=緯度,経度` で市役所の位置に開くことを確認。
- 笛吹市: 「[ふえふきわが街ガイドマップ](https://www2.wagmap.jp/fuefuki/Portal)」（wagmap）に市道の路線網図（mid=4）。道路種別は県。
- ほかの市町村: 市町村の独自の道路図はウェブ検索で見つからなかった（富士吉田・都留・大月・韮崎・南アルプス・北杜・甲斐・上野原・甲州・中央・市川三郷・身延・富士川・昭和・西桂・忍野・山中湖・富士河口湖は wagmap のポータルも無い）。県GISと建設事務所で確認する。

## 残り（次にやること）

- 県GIS（まっぷDE山梨）の地図の中心一致を、日本国内の回線で確かめる。
- 市町村の道路台帳（市道の幅員）の公開は個別に確認していない市町村が多い。
