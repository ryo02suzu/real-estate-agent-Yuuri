# PDF の分割図（図郭）で公開している市

道路図を「図1枚＝PDF1ファイル」で公開している市では、物件の位置が載っている図を
アプリが選んで直接開く（`lib/roadmap/sheets.ts` の `findSheet`）。
図ごとの範囲は `lib/roadmap/data/sheets/<市>.json` に前もって求めておく。

`cells` は `[図の名前, URL, 中心経度, -中心緯度, 幅(度), 高さ(度)]`（`M` は x=経度, y=-緯度 の恒等変換）。
桐生市だけは索引図の座標で持ち、`M` で緯度経度に変換する。

図どうしが重なるときは、物件が中心寄りにある図を選ぶ。端に近いときは隣の図も出す。
どの図にも入らない場所は、これまでどおり市の一覧ページを開く。

確かめ方：市役所など分かっている地点で、図の上の位置と地理院地図を並べて見る。
`lib/roadmap/roadmap.test.ts` に市ごとに1点以上のテストがある。

## 対応していない市

- 日光市の足尾・栗山など：市が図を公開していない地域（全体図に枠が無い）
- 西東京市：1枚のPDFなので、そのPDFを直接開く
