# PDF の分割図（図郭）で公開している市

道路図を「図1枚＝PDF1ファイル」で公開している市では、物件の位置が載っている図を
アプリが選んで直接開く（`lib/roadmap/sheets.ts` の `findSheet`）。
図ごとの範囲は `lib/roadmap/data/sheets/<市>.json` に前もって求めておく。

`cells` は `[図の名前, URL, 中心経度, -中心緯度, 幅(度), 高さ(度)]`（`M` は x=経度, y=-緯度 の恒等変換）。
桐生市だけは索引図の座標で持ち、`M` で緯度経度に変換する。

図どうしが重なるときは、物件が中心寄りにある図を選ぶ。端に近いときは隣の図も出す。
どの図にも入らない場所は、これまでどおり市の一覧ページを開く。
市全体で1枚の図（`cells` が1つ）は、画面で「市全体の図」と呼び、物件が図のどのあたりかだけを出す。

## 対応していない市

- 日光市の足尾・栗山など：市が図を公開していない地域（全体図に枠が無い）
- 新座市：以前は位置指定道路の PDF（21枚、図の名前が図郭番号）を開いていたが、2026年8月のにいざマップ刷新で全種別の Web 地図（建築基準法指定道路図）ができたため、そちらを物件の位置で開く

## PDF を物件の場所で拡大して開く（PC の Chrome・Firefox、2026-11-21）

PC の地図ボタンは、PDF の URL の後ろに `#page=頁&zoom=倍率,左,上` を付け、物件の場所を真ん中にして開く（`lib/roadmap/sheet-pdf.ts`）。
見える幅は約 300m（窓の大きさから倍率を決める。25〜500% に収める）。物件が図の範囲のどこか（`SheetHit.at`、左上 0・右下 1）を、
下の表の「図の範囲が頁の上で来る所」に当てはめて頁の上の点にする。図の端のときは頁の中に寄せる。隣の図のリンクも同じように開く。

「左,上」の読み方はブラウザで違う（ソースで確かめ、本物のブラウザで開いて確かめた）：

| ブラウザ | 読み方 | 出典 |
| --- | --- | --- |
| Chrome（Chromium の PDF ビューア） | 頁の左上からの、倍率 100% の画面の画素（1/96 インチ＝pt の 4/3 倍、下向き）。頁のまわりに上 3・左 5 画素の余白。倍率は 25〜500% | chromium/src の `chrome/browser/resources/pdf/open_pdf_params_parser.ts`・`viewport.ts`（goToPageAndXy）、`pdf/pdfium/pdfium_engine.cc`、`pdf/document_layout.h`、`third_party/blink/common/page/page_zoom.cc` |
| Firefox（pdf.js） | PDF の座標（pt、頁の左下が原点で上向き、頁の回転の前の向き。整数に切り捨て） | mozilla/pdf.js の `web/pdf_link_service.js`（setHash）・`web/pdf_viewer.js`（scrollPageIntoView） |
| Safari（WebKit） | `#` の後ろの最初の1つ（`page=` か `nameddest=`）だけ。倍率・位置は読まない | WebKit の `UnifiedPDFPlugin.mm`（revealFragmentIfNeeded） |
| Edge | Microsoft が作り替えた PDF ビューア。この作業の環境では動かせず、確かめていない | — |

規格（RFC 8118 の 3章・ISO 32000-2）は「pt で、頁の左上から右・下へ」と書いているが、Chrome も Firefox もそのとおりではない。
そこで PC の画面でブラウザを見分け（`pdfViewerOf`）、Chrome と Firefox だけに付ける。Edge・Safari・スマホは今までどおり図の全体が開く。
Chrome 153（Xvfb の画面ありで起動）と Firefox 155（pdf.js）で、草加市・福島県・大仙市（90° 回した頁）・北区（10枚綴りの2頁目）・文京区（90° 回した頁の端）の URL を開き、
物件が真ん中（頁の端では頁の中に寄せた位置）に来ることを確かめた。

### 図の作りごとの測り方

図の作り（市ごとの図の様式）ごとに本物の PDF を1〜数枚取り、頁の大きさ・回転（/Rotate）・図の枠の線や矩形の位置（pt、画面に出る向き）を PDF の中から読んだ。
データの図の範囲（`cells`）と枠の大きさ・縦横比が合うかを見て、地理院地図（標準地図）を同じ範囲に並べ直して重ね、目印（市役所など）と図の中の4か所で
道路の線のずれを相互相関で測った。枠の位置が図によって少し違う作りは間を取り、作りが2通りある市は図の名前で分けた。
