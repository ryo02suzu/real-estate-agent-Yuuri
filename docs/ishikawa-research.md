## 県の仕組み

- 特定行政庁は石川県と金沢市・七尾市・小松市・加賀市・白山市・野々市市。能美市は限定特定行政庁。県の「[建築基準法の施行に関すること](https://www.pref.ishikawa.lg.jp/kenju/kijyuhou.html)」（2025年8月7日更新）の「個別物件の相談窓口」の表: 能美市・川北町（能美市は建築基準法施行令148条1項1号・2号の建築物を除く）→ 南加賀土木総合事務所 建築課 0761-21-3333、かほく市・津幡町・内灘町 → 津幡土木事務所 建築課 076-289-4162、羽咋市・志賀町・宝達志水町・中能登町 → 中能登土木総合事務所 建築課 0767-52-7604、輪島市・珠洲市・穴水町・能登町 → 奥能登土木総合事務所 建築課 0768-26-2353、金沢市 → 都市整備局 建築指導課 076-220-2326、七尾市 → 建設部 都市建築課 0767-53-8429、小松市 → 都市創造部 建築住宅課 0761-24-8105、加賀市 → 建設部 建築課 建築指導室 0761-72-7935、白山市 → 建設部 建築住宅課 076-274-9561、能美市（148条1項1号・2号の建築物に限る）→ 土木部 まち整備課 0761-58-2251、野々市市 → 土木部 建築住宅課 076-227-6136。
- 能美市: 「[確認申請を行う際の注意点](https://www.city.nomi.lg.jp/docs/918.html)」に「本市は平成19年（2007年）4月1日から限定特定行政庁として、建築主事を設置しています」「（主に木造2階建てまでの一般住宅）や、一部工作物の確認申請および検査事務、また道路位置指定に関する事務などを行います」。窓口は[まち整備課（寺井分室1階、受付は午前9時〜正午）](https://www.city.nomi.lg.jp/docs/898.html)。限定特定行政庁が扱う事務は[建築基準法施行令148条](https://laws.e-gov.go.jp/law/325CO0000000338)（3項3号に42条1項5号・2項の指定）。
- 県は指定道路図をネットに出していない（県のサイトに位置指定道路の申請様式はあるが、地図は見つからなかった）。
- **都市計画区域の無い町**: 宝達志水町・中能登町。県の「[白地地域における容積率・建ぺい率制限等](https://www.pref.ishikawa.lg.jp/kenju/siraji/sirajitop.html)」に「現在17地域、17市町に都市計画区域を指定」とあり、挙がる市町（金沢・小松・白山・七尾・加賀・野々市・珠洲・能登・輪島・穴水・志賀・羽咋・かほく・津幡・内灘・川北・能美）に2町は無い。県の[中能登地域 広域都市圏マスタープラン](https://www.pref.ishikawa.lg.jp/toshi/masterplan/documents/kouiki-nakanoto.pdf)も「中能登地域は七尾市、羽咋市、志賀町、宝達志水町、中能登町の２市３町で構成され、このうち３市町で都市計画区域が指定されている」（七尾・羽咋・富来・志賀の区域）。県の「[いしかわの土木2022](https://www.pref.ishikawa.lg.jp/toshi/documents/ishikawanodoboku-toshikeikakuka.pdf)」も「県内には、17の都市計画区域があります」（令和4年3月現在）。「都市計画区域外」と表示し、道路図は出さない。
