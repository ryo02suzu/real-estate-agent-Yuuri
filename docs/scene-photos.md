# 町の写真（最近の検索のカード）

ホームの「最近の検索」のカードに、物件のある町のようすに合う写真を出す。その土地の本当の写真は出せないので、
町の種類ごとに用意したイメージ写真から選ぶ（カードの下に「写真は町のようすのイメージです（物件の写真ではありません）」と出す）。

今は届いた10枚（`public/home/scenes/`）のうち、住宅地の4枚から物件ごとに1枚を仮に出している（`lib/app/scene.ts`）。
町の種類を選ぶ仕組みは、写真の種類がそろってから作る。

## 写真の作り方（お願い）

- **文字を入れない。** ラベル（「田舎の住宅地」など）、看板、駅名、店名も入れない。今の10枚は文字入りなので、文字なしの版がほしい。名前はアプリが必要なときに描く。
- **有名な建物を入れない。** 東京タワー・スカイツリー・富士山の大写しなど。同じ写真を関東のいろいろな町に出すので、特定の場所に見えると違う町で困る。
- **人の顔が分かる大きさや、車のナンバーを写さない。**
- **今の10枚と同じ調子にそろえる。** 晴れた昼、夏の緑、明るい色。
- **大事なものを真ん中の横の帯に置く。** カードでは横長（幅2.5：高さ1くらい）に切り抜くので、上下が切れる。
- **形と大きさ：** 正方形か横長（4:3）。長い辺が1200px以上。PNG か JPG。
- **1枚ずつのファイルで、ファイル名を写真の名前に。** 例：「下町の住宅密集地_1.png」。並べた1枚の絵でも、こちらで切り分けられる。
- **同じ種類を2〜3枚。** 近くの物件を続けて調べても、同じ写真が並ばないように。

## アプリが町の種類を選ぶときのデータ（あとで作る）

どれも物件の地点で読み、住所はサーバーに送らない（ほかの国のデータと同じ作り）。

1. **都市計画：** 用途地域（住居・商業・工業）、市街化調整区域、都市計画区域の外。すでにある。
2. **地形：** 山地・丘陵・台地・低地・埋立地・海岸の砂地など。液状化のデータの地形区分で、すでにある。
3. **土地の使われ方：** 田・畑・森林・建物・海浜・湖沼・ゴルフ場など（国土数値情報の土地利用細分メッシュ）。新しく取り込む。
4. **人と駅：** 人口の密度、駅までの距離と駅の乗降客数。すでにある。
5. **建物：** 建物の高さと種類（PLATEAU のある市）、大規模盛土造成地。すでにある。
6. **海・湖・大きな川への近さ：** 海岸線・湖沼・河川のデータ。新しく取り込む。
7. **特別な町：** 温泉地・別荘地・島は、市町村名と町名の一覧で決める。

当てはまる種類の中から、物件ごとに決まった1枚を出す。どれにも当てはまらないときは「郊外の戸建て街」にする。
選んだ種類は検索履歴に一緒に残し、次に開いたときに同じ写真を出す。
